## PBMC3k-Scanpy-Practice
Author:Tengyi Guo
## Overview
This repository documents my learning process for single-cell RNA-seq analysis using the PBMC3k dataset with Scanpy.
## Goal
-Learn the standard single-cell analysis workflow.
-Record code,notes,and results step by step.
-Build a reproducible learning project.
## Roadmap
-[] Data loading and quality control<br>
-[] Normalization and highly variable gene selection<br>
-[] PCA and Neighborhood Graph<br>
-[] Clustering and UMAP Visualization<br>
-[] Marker Gene Identification<br>
-[] Cell Type Annotation<br>
-[] Differential Expression<br>
-[] Functional Enrichment<br>
-[] Trajectory and Pseudotime<br>
-[] RNA Velocity<br>
-[] Cell-Cell Communication<br>
-[] Gene Regulatory Network<br>
## Tools
-Python<br>
-Scanpy<br>
-Jupyter Notebook<br>

The PBMC3k datasetis publicly available from 10X Genomics.Raw data will not be uploaded to this repository.
