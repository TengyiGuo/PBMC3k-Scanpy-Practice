## PBMC3k-Scanpy-Practice
Author:Tengyi Guo
## Overview
This repository documents my learning process for single-cell RNA-seq analysis using the PBMC3k dataset with Scanpy.
## Goal
-Learn the standard single-cell analysis workflow.
-Record code,notes,and results step by step.
-Build a reproducible learning project.
## Roadmap
-[] Data loading and quality control
-[] Normalization and highly variable gene selection
-[] PCA and dimensionality reduction
-[] Clustering and UMAP visualization
-[] Marker gene identification and cell type annotation
## Tools
-Python
-Scanpy
-Jupyter Notebook
## Data
The PBMC3k datasetis publicly available from 10X Genomics.Raw data will not be uploaded to this repository.
